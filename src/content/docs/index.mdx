## Current dashboard features

The operator UI is designed to recover from the common Docker + emulator failure modes without
editing SQLite or shelling into Redis:

- **Device management** can scan live ADB ports, add a device manually when scan misses it, remove
  stale devices, and override capture/input backends per device.
- **Bot control** reflects fleet workers running inside Docker, so the sidebar does not stay
  "Stopped" when a worker is already alive.
- **Click approvals** show captured frames, rolling screenshots, and live scrcpy video when the
  device backend supports it.
- **Mail scenarios** read tab badges from the mail tab strip, so messages hidden behind another tab
  can push the right claim scenario.
