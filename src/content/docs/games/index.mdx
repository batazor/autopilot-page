## Want another game?

Got a similar survival / city-builder / 4X mobile game you'd like to automate? The engine is game-agnostic — adding one is just authoring a new `modules/<game>/` scenario set on top of the existing overlay engine, scheduler, and Web UI. If you have a candidate in mind (or want to co-author one), come chat in the [Discord](https://discord.gg/62twnzKG9) — happy to scope it together.
