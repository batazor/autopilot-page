:::note[One-time setup — Host networking]
The containers share the host loopback through **host networking**, which is how
the bot reaches the emulator on `127.0.0.1`. Turn it on once in Docker Desktop —
without it the bot can't see the emulator.
:::

<details open class="screenshot-details">
<summary>Show me where to click — Settings → Resources → Network</summary>

<Steps>

1. Open **Settings** — the ⚙️ gear icon in Docker Desktop's top bar.

2. Go to **Resources → Network**.

3. Tick **Enable host networking**, then **Apply & restart**.

</Steps>

## 1. Install Docker Desktop

Docker Desktop (it ships with Compose v2) is the only thing you install — you
**don't** need `adb` or any Android tools on the host. The bot container brings
its own copy and connects to the emulator for you.

<Tabs syncKey="mac-install">
  <TabItem label="Homebrew">
    ```sh
    brew install --cask docker                       # Docker Desktop
    ```

    Launch Docker Desktop once so the engine starts, then enable Host
    networking (note above).
  </TabItem>

  <TabItem label="Manual">
    Download [Docker Desktop for Mac](https://docs.docker.com/desktop/install/mac-install/)
    (pick the **Apple silicon** or **Intel** build for your Mac), install it, and
    enable Host networking (note above).
  </TabItem>
</Tabs>

Verify it's ready:

```sh
docker compose version   # Compose v2.x
```

## 2. Run the stack

<Steps>

1. **Fetch the compose file**

   ```sh
   curl -fsSL https://batazor.github.io/autopilot-page/docker-compose.prod.yml -o docker-compose.prod.yml
   ```

2. **Set the emulator profile** — **720 × 1280 @ 320 DPI**, game language
   **English**, with **Android Debug Bridge** enabled in the emulator's settings.
   See [Emulator setup](/config/emulator/); the dashboard warns you
   if the resolution or DPI is off.

3. **Pull and start** redis + bot + api + web:

   ```sh
   docker compose -f docker-compose.prod.yml up -d --pull always
   ```

4. **Open the dashboard**

   ```sh
   open http://127.0.0.1:3000/overview
   ```

</Steps>

:::note[First start]
The bot service starts automatically — no activation step is needed. Open the
dashboard, go to **Devices (ADB)**, and your emulator shows up ready to add.
:::

## Troubleshooting

<Aside type="caution" title="Bot can't see the emulator">
Almost always the **Host networking** toggle is off — re-check Docker Desktop →
Settings → Resources → Network and **Apply & restart**. Also confirm the
emulator's **Android Debug Bridge** is enabled. Then open the dashboard's
**Devices (ADB)** page and press **Rescan**; it re-discovers and connects for
you. Still stuck? Restart the emulator and the stack with
`docker compose -f docker-compose.prod.yml restart`.
</Aside>

See [Troubleshooting](/ops/troubleshooting/) for the full list.
