The bot core is **free** (the R2 tier). A license file is still required — it carries your tier, expiry and usage limits (max devices, max players per device, external-account cap), and lets us rotate keys without releasing a new image.

Tiers are named after in-game alliance ranks. **Features are cumulative** — a higher tier includes everything below it.

R3 / R4 keys are **free** for people helping the project — module development & debugging, labeling, and active testing of pre-release builds. DM a maintainer on [Discord](https://discord.gg/62twnzKG9) with your host fingerprint (shown on the dashboard's **License** page).
:::

## Usage limits

Every license also carries usage caps, independent of the tier's feature list:

| Claim | Free shared key | Paid (R3 / R4) |
|:---|:---|:---|
| Host binding | Any host (one shared key) | Bound to your machine fingerprint |
| Devices (emulator instances) | **2** | Per request (default 1, up to 100) |
| Players per device | **3** | **3** (up to 100) |
| External gift-code accounts (per game) | 0 | 5 (R3) / 50 (R4) |
| Validity | Monthly key rotation in [Discord](https://discord.gg/62twnzKG9) | Issued per request |

The paid key won't run on a different host — copy your fingerprint from the dashboard's **License** page when requesting one.

## When the key expires

Free keys rotate every so often. When yours stops working:

1. Pull the latest `licence.jwt` from the `#install` channel on [Discord](https://discord.gg/62twnzKG9)
2. Re-upload it through the same UI flow

Paid keys are issued with their own expiry — DM a maintainer to renew.
